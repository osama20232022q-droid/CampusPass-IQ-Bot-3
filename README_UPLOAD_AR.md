# CampusPass IQ V8.1 — نسخة Railway/GitHub

هذه الحزمة مهيأة لواجهة GitHub التي لا تسمح برفع أكثر من 100 ملف دفعة واحدة.

## الرفع
ارفع **الملفات الثمانية فقط** الموجودة في هذا المجلد إلى جذر مستودع GitHub واستبدل الملفات القديمة.

**لا تفك `source_bundle.zip` داخل GitHub.** يقوم Dockerfile بالتحقق من SHA-256 ثم يفك الحزمة داخل Railway أثناء البناء.

## أهم ما في V8.1
- محفظة المستخدم: فائض الدفع يُحفظ تلقائياً، والمبلغ الناقص لا يُقبل إلا إذا غطت المحفظة كامل الفرق.
- أكواد خصم للطلبات: عامة أو خاصة بمنصة.
- تحصيل رسوم CampusPass من المنصات مع وصل MasterCard ومراجعة المالك.
- حظر المنصة عند عدم الامتثال: إخفاء عروضها وإيقاف الطلبات المفتوحة مع إشعار المستخدمين.
- سجل إداري أوضح لكل مستخدم مع الطلبات والاشتراكات والمحفظة.
- شعار المنصة محفوظ داخل قاعدة البيانات ويظهر في التقارير؛ الشعار إلزامي للتقارير.
- تجميع عناصر الحساب تحت زر «حسابي» وتقليل ازدحام الصفحة الرئيسية.
- تحريك أزرار الواجهة بالأسهم بدل أرقام الصفوف والأعمدة.
- إزالة رسالة «تم إلغاء الخطوة السابقة وفتح القسم الجديد» من التنقل الطبيعي.
- إصلاح مسار Gemini بحيث يكون التحكم من Feature Flag وقيمة API Key.

## ملاحظة Gemini
الحزمة تضبط القالب المستقبلي على `FEATURE_GEMINI=true`. على Railway الحالي يمكن إبقاء المتغير كما هو لأن ترقية V8.1 تفعّل Feature Flag الخاص بـ Gemini، لكن يجب أن يكون `GEMINI_API_KEY` صالحاً.
